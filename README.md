# Marketing Campaign Response Prediction

Проект по прогнозированию отклика клиентов на маркетинговую кампанию.

## Задача
Построить модель бинарной классификации для прогнозирования вероятности положительного отклика клиента.

## Стек
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn.

## Что реализовано
- Предобработка данных и анализ признаков
- Pipeline и ColumnTransformer
- RidgeClassifier, Random Forest, Gradient Boosting
- Подбор гиперпараметров с GridSearchCV
- Стратифицированная 5-кратная кросс-валидация
- Оценка качества по Average Precision и ROC-AUC
